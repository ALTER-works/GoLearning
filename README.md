# 🐹 Go Student Tasks (Tasks_Ntlg)

This repository contains a collection of practical programming tasks and solutions written in **Go (Golang)** as part of my learning journey. Each task is organized into its own module/package.

## 📁 Repository Structure

* **Task2/** — first words layout.
* **Task3/** — first work with fstrokes and types in GO. Plus extra work with struct.
* **Task4/** — Modular code structure:
  * `extra/` — extra work, based on "main" model. Simple managment program
  * `main/` — first work with different types. Also, a basik work with functions.
* **Task5/** — first work with if-else and switch.
* **Task6/** — first work with errors and files.

## 🛠️ Tech Stack
* **Language:** Go (Golang)
* **Dependency Management:** Go Modules (`go.mod` included in packages)

## 🚀 Getting Started

### Prerequisites
Make sure you have [Go installed](https://go.dev) on your machine.

### Installation & Running
1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate to a specific task folder (e.g., Task2):
   ```bash
   cd Tasks_Ntlg/Task2
   ```
3. Run the application:
   ```bash
   go run main.go
   ```
