# Todo App

Консольное приложение (CLI) на языке Go для управления списком задач с возможностью фильтрации и сохранения данных.  
Приложение реализовано на базовых библиотеках go.

## Архитектура проекта

* `cmd/todo/main.go` — точка входа в приложение.
* `internal/todo/` — бизнес-логика (менеджер задач, структура задачи).
* `internal/storage/` — абстракция хранилища данных (работа с файлами JSON/CSV и утилиты).
* `data/` — директория для хранения базы данных (`tasks.json`).
* `internal\storage\testdata` — файлы CSV и JSON для возможных тестов функционала.

## Основные функции

* **add** — добавление новой задачи.
* **complete** — отметка задачи как выполненной.
* **delete** — удаление задачи из списка.
* **list** — вывод списка задач с поддержкой различных фильтров.
* **save** — принудительное сохранение текущего состояния.
* **load** — загрузка/импорт сохраненных задач (поддерживает JSON и CSV).

## Хранение данных

Все задачи по умолчанию сохраняются в локальный файл базы данных:
 `data/tasks.json`

## Сборка и запуск

Сначала соберите исполняемый файл в корневой директории проекта (где лежит `go.mod`):

* **Windows:**
```
go build -o todo-app.exe ./cmd/todo
```

* **Linux/macOS:**
```
go build -o todo-app ./cmd/todo && chmod +x todo-app
```

### Примеры использования:

* **Добавление задачи:**
  ```bash
  ./todo add --desc="Купить книги"
  ```
* **Загрузка/Импорт данных (из CSV):**
  ```bash
  ./todo load --file=tasks_export.csv
  ```

## Тестирование

Для запуска тестов менеджера задач (`manager_test.go`):

```bash
go test ./internal/todo -v
```
